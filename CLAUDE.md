# Project guardrails for Claude Code

You are working on NOIR, a portfolio-quality creative landing page using Next.js App Router, React, TypeScript and vanilla CSS.

- Preserve the distinctive editorial design. Avoid generic SaaS templates.
- Keep the experience responsive and accessible, including keyboard operation and reduced-motion handling.
- Do not add dependencies unless the requirement justifies them.
- Before changing code, summarize proposed changes, impacted files and validation steps.
- Never fabricate client projects, testimonials, awards, performance metrics or employment history.
- Keep conceptual case studies clearly labeled as conceptual.
- Validate with `npm run build` and check mobile, tablet and desktop layouts.
- Prefer lightweight animation and keep text readable at small viewport sizes.
